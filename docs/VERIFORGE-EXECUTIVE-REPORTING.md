# VeriForge Executive Reporting Suite

Industrial-grade dashboards, summaries, and predictive insights using the forged-metal identity.

## Features

- Executive dashboards
- KPI summaries
- Compliance overviews
- Incident analytics
- Risk intelligence
- Workforce readiness
- Equipment health
- Predictive insights
- Export-ready report layouts

## Report types

| # | Type | Contents |
|---|------|----------|
| 1 | Executive Summary | Composite readiness · critical KPI accent line |
| 2 | Training | Completion · overdue · certifications |
| 3 | Verification | forgeCheck pass rate · workflow time · failures |
| 4 | Compliance | Validity · coverage · expiry forecast · gaps |
| 5 | Incident | Frequency · severity · root cause · closure |
| 6 | Risk | Hazard density · controls · score trends · matrix |
| 7 | Equipment | Inspections · defects · cert expiry |
| 8 | Workforce Readiness | Training · verification · compliance readiness |
| 9 | Predictive Insights | AI forecasts · metallic trends · predicted risks |

## Report rules

- Metadata on every report: `timestamp`, `region`, `tenantId`
- Critical KPIs trigger red metallic notifications
- Export-ready angular layouts with metallic headers

## Brand

Black panels `#1A1A1A` · Steel-grey charts `#424242` · Forge red `#C62828` · Angular metallic cards · Orbitron typography
