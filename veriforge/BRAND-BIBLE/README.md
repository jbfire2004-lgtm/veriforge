## Non-negotiables (one page)

1. Palette: `#C62828` · `#0D0D0D` · `#424242` · `#FAFAFA` only as primary system  
2. Geometry: `border-radius: 0` everywhere  
3. Type: Orbitron headings · Exo 2 body  
4. Shell: `VFAppShell` / VeriForge shells — never Vera unified nav on VeriForge  
5. Red: active, focus, critical — intentional, never decorative spam  
6. Motion: 120 / 240 / 400ms · critical pulse only on critical  
7. Voice: strong, engineered, industrial, precise, confident — no fluff, no softness
