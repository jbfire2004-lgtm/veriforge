# Examples

Canonical compositions. Build against live routes; stills must match this bible.

---

## Dashboard

**Route:** `/veriforge/dashboard`

| Element | Brand application |
|---------|-------------------|
| Shell | VFAppShell · metallic header · steel sidebar |
| KPI cards | Metallic gradient headers · angular · steel borders |
| Charts | Angular bar rise · metallic line draw · labeled |
| Alerts | Critical = red metallic glow **+** “Critical” text |
| Motion | Section metallicFade; no pulse on every KPI |

**Hero still brief:** One composition — brand chrome + KPI metal + one red critical alert.
