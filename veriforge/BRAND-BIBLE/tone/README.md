# Tone & Voice

## Attributes (locked)

| Attribute | Meaning |
|-----------|---------|
| **Strong** | Load-bearing language. Short sentences. Hard nouns. |
| **Engineered** | Process, precision, systems — not vibes. |
| **Industrial** | Machinery, forge, steel, command — not lifestyle. |
| **Precise** | Specific engines, outcomes, and actions. |
| **Confident** | Declarative. No hedging theater. |
| **No fluff** | Cut adverbs and empty superlatives. |
| **No softness** | No “delight,” “seamless magic,” or cuddly SaaS copy. |

## Master lines

- Forged for Absolute Safety  
- Safety engineered, not improvised.  
- Industrial-Grade Verification  
- Engineered Compliance  
- Angular Workflows. Metallic Precision.  
- Safety Built Like Machinery.  

## Voice do / don't

| Do | Don't |
|----|-------|
| Forge, engineer, verify, seal, escalate, command | Delight, empower, seamlessly, magical |
| “Critical when it counts.” | “We’re passionate about safety ❤️” |
| Name the engine | Vague “AI-powered platform” as the whole story |
| Active voice | Passive corporate fog |
| One idea per sentence | Stacked clauses and buzzword chains |

## Grammar of the forge

- Prefer **fragments** for posters and heroes; full sentences for docs and legal.  
- Headlines: Orbitron energy — uppercase in UI chrome where brand requires.  
- Body: Exo 2 — clear, readable, safetyWhite on iron.  
- Numbers and severities spelled with labels (“Critical”, not red alone).  

## Audience shifts (same voice, different density)

| Audience | Density |
|----------|---------|
| Product UI | Ultra terse · labels · status words |
| Docs | Precise · procedural · token names OK |
| Marketing | Punch lines + one proof sentence |
| Sales | Industrial confidence + measurable levers |
| Partners | Rules + obligations · no hype |

## Critical / incident language

- Always include severity word  
- Never joke on critical surfaces  
- Prefer “Acknowledge / Escalate / Close” over casual slang  

## Examples

**On-brand:**  
> Fragmented tools create risk. VeriForge forges training, verification, and compliance into one industrial platform.

**Off-brand:**  
> We’re thrilled to supercharge your safety journey with a delightful, all-in-one experience!

## Review checklist

- [ ] Could this line sit on an iron-black poster with a red rail?  
- [ ] Any fluff or softness to cut?  
- [ ] Is red meaning also written in words?  
- [ ] Tagline used correctly (not over-chanted)?
