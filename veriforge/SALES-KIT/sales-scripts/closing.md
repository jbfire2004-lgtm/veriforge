# Closing Script

**Goal:** Convert validated interest into a clear commercial next step.

## Preconditions

- [ ] Demo completed with champion + at least one influencer  
- [ ] Pain mapped to ≤3 engines  
- [ ] ROI inputs received or scheduled  
- [ ] Security/tenancy questions listed  

## Close frame (use verbatim structure)

> You’ve seen the forge: unified engines, industrial UI, tenant-aware architecture. The cost of waiting is another quarter of improvised handoffs. I recommend we lock a pilot scope — [engines] on [sites/BU] — with success metrics we both sign.

## Commercial options (pick one)

1. **Pilot** — 60–90 days · 1–2 sites · 2–3 engines · weekly forge review  
2. **Phased enterprise** — Pilot → regional → global (deployment playbook)  
3. **Executive workshop** — Architecture + ROI + security in one day, then proposal  

## Trial close questions

- “Is there any reason we wouldn’t start the pilot scoping this month?”  
- “Who signs alongside you for budget and security?”  
- “Which two KPIs must move for this to be a win?”  

## Proposal package to send same day

1. Pitch deck PDF (core 10)  
2. Engine one-pagers (scoped only)  
3. Industry brief  
4. Matching case study  
5. ROI worksheet (their numbers)  
6. Pilot SOW outline (engines, sites, timeline, success metrics)  

## Final line

> Forged for Absolute Safety. Let’s stop improvising — and start engineering.

## If they stall

> Understood. I’ll send the leave-behinds and book a 20-minute checkpoint in two weeks. If priorities shift to [compliance audit / season / outage], we can accelerate the Command Center or Compliance path alone.
