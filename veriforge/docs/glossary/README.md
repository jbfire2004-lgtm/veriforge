# Glossary

Forged-metal VeriForge terms.

| Term | Definition |
|------|------------|
| **forgeRed** | Brand accent `#C62828` — active, critical, focus |
| **ironBlack** | Primary background `#0D0D0D` |
| **steelGrey** | Structural chrome `#424242` — borders, hover; not body text on black |
| **safetyWhite** | Primary text/icon color `#FAFAFA` on dark |
| **metallicGradient** | `135deg` gradient `#1A1A1A → #2E2E2E → #424242` |
| **angular geometry** | `border-radius: 0` everywhere |
| **bevelEdge** | `6px` bevel token for press/edge treatments |
| **metallicShadow** | Red-tinted glow shadow for active/critical metal |
| **steelShadow** | Soft white glow for steel chrome |
| **angularSlide** | Route/panel slide motion (240ms) |
| **metallicFade** | Content fade motion (240ms) |
| **industrialDrop** | Modal drop-in motion |
| **redGlowPulse** | Critical-only red pulse |
| **bevelShift** | Sidebar/nav bevel motion |
| **VFAppShell** | VeriForge workspace shell (not Vera global nav) |
| **VF*** | Forged-metal component prefix (`VFButton`, `VFCard`, …) |
| **forgeStatus** | API meta field (`verified`, `forged`, …) |
| **tenantId** | Tenant isolation key in JWT, routes, and API meta |
| **critical route** | Route that must show red critical treatment / pulse |
| **Orbitron** | Display/heading font |
| **Exo 2** | Body font |
| **VeriForge** | Industrial safety platform identity within the Vera monorepo |
| **Vera nav** | Unified Vera navigation — **forbidden** on VeriForge pages |
| **vf-debug** | Theme debug toolkit flag on `<html>` |
| **COR / OSHA / ISO** | Compliance frameworks referenced by Compliance Engine |
