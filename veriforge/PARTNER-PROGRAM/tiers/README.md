# Partner Tiers

Three industrial tiers: **Forge** (entry) · **Alloy** (mid) · **Titanium** (elite).

Visual: metallic tier badges · steel frames · forge-red underline on active tier name · angular geometry only.

---

## Tier summary

| | Forge Partner | Alloy Partner | Titanium Partner |
|---|---------------|---------------|------------------|
| **Position** | Entry | Mid | Elite |
| **Focus** | Learn · resell · light integrate | Deploy · certify · integrate | Scale · co-sell · shape roadmap |
| **Badge** | Steel | Steel + red rail | Metallic + red glow mark |
| **PSM** | Pooled | Named (shared) | Dedicated partner success manager |

---

## Forge Partner (entry)

**Who:** New resellers, boutique integrators, training affiliates starting on VeriForge.

### Requirements

| Area | Minimum |
|------|---------|
| Deployments | **1** production or paid pilot tenant |
| Certifications | **Forge Certified** (min. 1 individual) |
| Integrations | Sandbox API access; optional read-only webhook |
| Support capabilities | Email L1 to end customer; escalate to VeriForge within SLA |

### Capabilities unlocked

- Partner portal access  
- Standard reseller discount (see reseller program)  
- Sales kit + marketing launch assets  
- Public API docs + sandbox keys  
- Listing as Forge Partner (directory)  

---

## Alloy Partner (mid)

**Who:** Regional VARs and integrators with repeatable delivery.

### Requirements

| Area | Minimum |
|------|---------|
| Deployments | **5** active production tenants (trailing 12 months) |
| Certifications | **Alloy Certified** delivery lead + **Forge Certified** for SE/AE bench (min. 2 people) |
| Integrations | ≥1 production integration (SSO, HRIS, LMS, or webhook consumer) passing tenant isolation review |
| Support capabilities | L1–L2; 8×5 coverage; documented runbooks; severity definitions aligned to VeriForge |

### Capabilities unlocked

- Higher revenue share / discount band  
- Co-marketing (joint webinar / case study eligibility)  
- Priority support queue  
- Early access to **non-critical** engine betas  
- Shared partner success manager  
- Alloy badge on directory + proposals  

---

## Titanium Partner (elite)

**Who:** Strategic global/regional partners with industrial delivery muscle.

### Requirements

| Area | Minimum |
|------|---------|
| Deployments | **15** active production tenants **or** ≥1 enterprise multi-site program (≥8 sites) |
| Certifications | **Titanium Certified** architect + Alloy Certified delivery team (min. 3 certified) |
| Integrations | ≥2 production integrations including one of: ledger commit consumer, digital twin ingestion, or Command Center webhook automation — security reviewed |
| Support capabilities | L1–L3 capable; 16×5 or better; named escalation contacts; participate in joint war-rooms for severity-1 |

### Capabilities unlocked

- Top revenue share / deal registration priority  
- Full co-marketing fund eligibility  
- Highest priority support + dedicated PSM  
- Early access to **all** engine betas (including critical surfaces under NDA)  
- Roadmap influence sessions (quarterly)  
- Titanium badge · joint press eligibility · preferred listing  

---

## Progression

```
Apply → Forge Certified → First deployment → Forge Partner
     → Alloy Certified + 5 tenants + integration → Alloy Partner
     → Titanium Certified + scale/support bar → Titanium Partner
```

Annual review: deployments, CSAT/escalations, brand compliance, certification currency.

## Demotion / probation

- Critical security violation (cross-tenant) → immediate suspension  
- Off-brand product chrome in customer-facing VeriForge embeds → 30-day remediation  
- Certification lapse → benefits freeze until renewed
