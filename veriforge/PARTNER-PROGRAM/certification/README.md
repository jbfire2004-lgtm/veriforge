# Partner Certification

Credentials: **Forge Certified** · **Alloy Certified** · **Titanium Certified**

Certificates use metallic gradient header · steel frame · forge-red accent line · Orbitron name · angular geometry · forged V emblem.

---

## Credential overview

| Credential | Level | Focus | Validity |
|------------|-------|-------|----------|
| **Forge Certified** | Entry | Product literacy · identity · basic workflows | 24 months |
| **Alloy Certified** | Mid | Delivery · integration · multi-engine projects | 18 months |
| **Titanium Certified** | Elite | Architecture · tenancy · ledger/twin · scale | 12 months |

---

## Forge Certified

### Audience

AEs, SEs, trainers, first integrator hires.

### Exam domains

| Domain | Weight |
|--------|--------|
| Forged-metal identity (color, type, geometry) | 15% |
| Engines overview + when to use which | 25% |
| Navigation / demo path literacy | 20% |
| Tenant basics + API envelope awareness | 15% |
| Sales kit / messaging (taglines, voice) | 15% |
| A11y / critical-red rules (high level) | 10% |

### Practical assessment

- 20-minute sandbox demo: Dashboard → one engine → show steel/red/angular correctly  
- Identify three brand violations in a mock screenshot  

### Pass

≥80% exam + practical pass.

## Alloy Certified

### Audience

Delivery leads, senior SEs, integration engineers.

### Exam domains

| Domain | Weight |
|--------|--------|
| Multi-engine solution design | 20% |
| Tenant-aware API + RBAC | 20% |
| Webhooks + isolation scenarios | 15% |
| Go-live / brand QA checklist | 15% |
| Support severity + escalation | 10% |
| ROI levers mapping to engines | 10% |
| Industry brief application | 10% |

### Practical assessment

- Design integration for one external system (diagram + tenant rules)  
- Configure/demo Training + Verification + Compliance path  
- Produce angular go-live checklist evidence pack  

### Pass

≥85% exam + practical pass · prerequisite: Forge Certified.

## Titanium Certified

### Audience

Partner architects, practice principals.

### Exam domains

| Domain | Weight |
|--------|--------|
| Enterprise + multi-tenant architecture | 25% |
| Safety Blockchain Ledger integration | 15% |
| Digital Twin ingestion design | 15% |
| Command Center / critical systems ops | 15% |
| Security anti-patterns + incident response | 15% |
| Scale delivery (15+ tenants / multi-site) | 15% |

### Practical assessment

- Architecture defense (60 min) before VeriForge panel  
- Twin **or** ledger integration lab in sandbox  
- Written: S1 cross-tenant near-miss response plan  

### Pass

≥90% exam + panel pass · prerequisites: Alloy Certified + evidence of Alloy-tier delivery.

## Claiming status

Partners may state:

- “Forge Certified [Name]”  
- “Alloy Certified Delivery Partner” (org — when headcount met)  
- “Titanium Certified Architect [Name]”  

Do **not** claim Titanium Partner **org tier** without meeting [`../tiers/`](../tiers/) deployment/support bars — certification alone is insufficient.

## Revocation

- Sharing exam content  
- Facilitating cross-tenant access  
- Persistent off-brand customer deliveries after warning  

PSM notifies; appeals via partner operations.
